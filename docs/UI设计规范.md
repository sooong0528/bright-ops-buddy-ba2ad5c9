# UI设计Agent规范提示词

你需要为企业级 **智能运维系统** 设计 **PC端工作台类页面**。

> **浅色专业 SaaS + 青蓝主题色 `#00C1BE` 的 PC端智能运维工作台，采用顶部品牌通栏 + 左侧主菜单 + 右侧主体工作区布局。**

------

# 1. 页面类型与整体布局

当前系统按 **PC端工作台类页面** 设计。

页面采用：

> **顶部品牌通栏 + 左侧主菜单 + 右侧主体工作区**

顶部通栏用于系统身份识别和全局辅助操作。
 左侧菜单作为系统主导航。
 右侧主体区承载当前页面内容。

## 必须包含

- 顶部品牌通栏
- 左侧主菜单区
- 右侧主体工作区
- 页面标题区
- 搜索 / 筛选 / 操作区
- 用户信息、通知或帮助入口

## 不采用

- 不采用门户式顶部横向多级菜单。
- 不采用顶部一级导航菜单作为主导航。
- 不采用纯指标大屏布局。
- 不采用全屏深色大屏风格。
- 不采用复杂双主导航结构。

## 适配要求

页面需适配：

- **1920px**
- **1440px**
- **1366px**

右侧主体内容需根据屏幕分辨率自适应缩放。

------

# 2. 顶部品牌通栏规范

顶部品牌通栏只用于系统身份识别和全局辅助操作，**不作为主导航使用**。

## 必须要求

- 顶部通栏固定在页面上方。
- 系统 Logo 位于顶部最左侧。
- Logo 距离左侧边缘 **20px**。
- 系统名称与 Logo 间距 **48px**。
- Logo、系统名称与顶部通栏背景需 **垂直居中对齐**。
- Logo 不得拉伸、压缩或变形。
- 顶部通栏右侧可放置用户信息、消息通知、帮助入口、全局搜索等辅助功能。
- 不在顶部通栏中放置一级菜单导航。
- 不在顶部通栏中放置多级横向菜单。

------

# 3. 左侧主菜单规范

左侧菜单作为系统主导航，位于顶部通栏下方。

## 必须要求

- 一级功能入口放在左侧菜单中。
- 高频功能优先展示。
- 低频功能可折叠或收纳。
- 菜单层级最多 **3级**。
- 当前选中菜单状态必须清晰。
- 菜单文字需简洁，不使用过长名称。
- 菜单图标风格需统一。
- 左侧菜单需支持当前页面定位。
- 菜单不应与顶部通栏形成重复导航。
- 不要把所有入口都做成卡片入口，应保证左侧菜单具备稳定导航能力。

------

# 4. 右侧主体工作区规范

右侧主体区承载当前页面内容。

## 必须要求

- 页面标题清晰。
- 当前页面状态清晰。
- 主操作按钮位置明确。
- 搜索、筛选、表格、详情、表单等区域结构统一。
- 内容区优先使用白色卡片承载。
- 背景建议使用浅灰或白色。
- 信息密度适中，适合长时间办公使用。
- 右侧主体内容根据屏幕分辨率自适应缩放。
- 页面标题、状态、主操作按钮应清晰可见。

## 页面内容组织要求

常规页面建议采用：

- 页面标题区
- 搜索 / 筛选区
- 主内容区
- 操作按钮区
- 分页 / 状态反馈区

详情或处理页面建议采用：

- 页面标题区
- 状态信息区
- 主内容区
- 辅助信息区
- 操作按钮区

------

# 5. 色彩规范

## 主题色

系统主题色统一使用：

> **`#00C1BE`**

## 整体风格

采用：

> **浅色专业 SaaS + 青蓝科技主题色**

## 使用要求

`#00C1BE` 主要用于：

- 主按钮
- 当前选中状态
- 重点操作入口
- 链接文字
- 高亮边框
- 搜索结果关键词高亮
- 关键数据强调
- 当前菜单选中状态

## 限制

- 不要大面积铺满使用 `#00C1BE`。
- 页面背景建议使用浅灰或白色。
- 内容区建议使用白色卡片。
- 红、黄、绿仅用于告警、预警、状态表达。
- 普通正文文字不得随意使用红、黄、绿。
- 告警颜色必须有明确语义，不得装饰性使用。
- 色彩使用需保持一致，不要在不同页面中随意变化主题色。

------

# 6. 字体规范

## 中文字体

使用系统自带字体：

- 苹方
- 微软雅黑
- 思源黑体

## 英文 / 数字字体

使用：

- Arial
- Helvetica
- sans-serif

## 限制

- 不得出现过大或过小字体。
- 不得出现错字、别字。
- 特殊字体需以图片形式输出。
- 页面文字层级需清晰。
- 标题、正文、辅助说明、数据数值需有明显区分。

## 建议字号

- 页面主标题：20–24px
- 模块标题：16–18px
- 正文内容：14px
- 辅助说明：12–13px
- 关键指标数字：24–36px

------

# 7. 图标规范

## 必须要求

- 图标必须简洁易懂。
- 同一场景下图标风格必须统一。
- 图标尺寸统一。
- 图标颜色统一。
- 图标线条粗细统一。
- 图标透视角度统一。
- 优先使用统一图标库。

## 限制

- 不要混用线性、面性、拟物等不同风格图标。
- 不要使用过度装饰化图标。
- 不要使用含义不清的图标。
- 菜单图标、按钮图标、状态图标需保持视觉一致。

------

# 8. 表单规范

## 必须要求

- PC端表单标签对齐方式必须统一。
- 标签使用冒号对齐。
- 必填项必须显示红色 `*`。
- 必填符号放在标签左侧。
- 表单需自动检测必填项或组合项是否完整。
- 输入错误时需及时提示。
- 提交、保存等结束性按钮放在表单下方。
- 复杂表单顶部需显示填写流程或当前位置。

## 操作按钮

- 主按钮用于提交、保存、确认。
- 次按钮用于取消、返回、重置。
- 删除、清空、终止等危险操作需二次确认。
- 主次按钮样式需有明显区分。
- 表单按钮位置需在同类页面中保持一致。

------

# 9. 表格规范

PC端复杂数据优先使用表格。

## 必须要求

- 表格必须使用隔行变色。
- 长文本超出时使用 `…`。
- 鼠标悬浮时显示完整文本。
- 普通文本左对齐。
- 金额右对齐。
- 多级表头高度统一。
- 表格文字垂直居中。
- 操作列避免堆叠过多按钮。
- 次要操作可放入“更多”。
- 表格筛选、排序、分页样式需统一。

------

# 10. 检索规范

## 必须要求

- 全局搜索按钮放在搜索框左侧。
- 输入框聚焦时，`Enter` 键执行搜索。
- 搜索结果关键词使用主题色 `#00C1BE` 高亮。
- 全局搜索需提供智能匹配下拉列表。
- 匹配项超过 **6条** 时显示滚动条。
- 搜索结果为空时必须给出缺省提示。
- 检索区与操作区应分组清晰，不要混杂排列。

------

# 11. 提示信息规范

以下场景必须出现提示信息：

- 新手使用
- 删除重要信息
- 误操作
- 中断操作
- 无权限访问
- 操作失败
- 网络异常
- 空数据

## 必须要求

- 图标放在文字前。
- 可点击文字和不可点击文字需区分。
- 不使用编程术语。
- 不使用双重否定。
- 内容过多时折行显示。
- 文案需说明问题和可执行的处理方式。

------

# 12. 加载状态规范

以下场景必须显示加载反馈：

- 页面刷新
- 页面跳转
- 数据加载
- 网络异常
- 查询执行
- 表单提交

## 必须要求

- 加载提示必须包含动态图标和提示文字。
- 短时操作使用按钮 Loading。
- 页面级加载使用局部 Loading 或骨架屏。
- 长时间任务使用进度条。
- 网络异常时提供重试入口。

------

# 13. 禁止方向

设计中避免以下方向：

- 不要做成门户展示页。
- 不要做成纯指标大屏。
- 不要做成全屏深色科技大屏。
- 不要使用顶部一级导航菜单作为主导航。
- 不要使用门户式横向多级菜单。
- 不要让顶部通栏和左侧菜单形成重复主导航。
- 不要让 `#00C1BE` 大面积铺满页面。
- 不要混用多种图标风格。
- 不要使用过多装饰性渐变和光效。
- 不要牺牲表格、表单、检索的可读性。
- 不要为了科技感降低信息清晰度。
